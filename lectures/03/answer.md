  `- 用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する。`

  変更前後で同一の質問「LoRAとQLoRAの違いは？」を使用し、`--trace` オプションによってツール呼び出しの回数、引数、回答内容、トークン数、APIコストを比較した。

  `uv run python -m app.agent --trace "LoRAとQLoRAの違いは？"`

  変更前
  - ツール呼び出し回数：2回
  - `search_glossary({'query': 'LoRA'})`
  - `search_glossary({'query': 'QLoRA'})`
  - LLM呼び出し回数（requests）：2回
  - 入力トークン数：1,196
  - 出力トークン数：169
  - APIコスト：$0.0007813

  変更後

- 気づき・疑問：

  今回の実験から、エージェントの指示内容がツールの選択や呼び出し回数に影響することを確認できた。特に、ツールの利用を必須とする指示を削除しても、モデルが必要と判断した場合には自律的にツールを利用することが分かった。
